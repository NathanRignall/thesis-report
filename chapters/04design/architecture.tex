During \autoref{chap:constraint-optimisation} we formulated a bounded bin‐packing problem, by constraining the islands to a pre‐defined type and size.
In a true scheduling problem we expect to be allocated an inventory of different GPU types, let \(T\) be the set of GPU types.
For each \(t\in T\), let \(n_t\) be the number of GPUs of type \(t\) allocated in the inventory.
The full GPU inventory is then the vector \(\bigl(n_t\bigr)_{t\in T}\), with total number of GPUs \(N = \sum_{t\in T} n_t.\).
